Phase 2, Module 10 — Playbooks

Theory​

Playbooks are YAML files that define the desired state of your systems:

  • Plays — Map hosts to tasks
  • Tasks — Individual module calls
  • Variables — Customize playbook behavior (vars:, vars_files:, include_vars:)
  • Facts — System information gathered automatically (ansible_facts)
  • Conditionals — when: to run tasks only under certain conditions
  • Loops — loop: to repeat tasks with different values
  • Handlers — Tasks that run only when notified (usually service restarts)
  • Jinja2 templates — Dynamic config files with {{ variables }}

Exam reality: You'll write playbooks that use variables, conditionals, loops, and templates to configure systems dynamically.

Try It​

# ~/ansible/vars-playbook.yml
---
- name: Configure web server with variables
  hosts: webservers
  become: yes
  vars:
    http_port: 80
    docroot: /var/www/html
    welcome_message: "Welcome to RHCE Lab"
  
  tasks:
    - name: Install httpd
      ansible.builtin.package:
        name: httpd
        state: present
    
    - name: Create document root
      ansible.builtin.file:
        path: "{{ docroot }}"
        state: directory
        mode: '0755'
    
    - name: Deploy index.html
      ansible.builtin.template:
        src: index.html.j2
        dest: "{{ docroot }}/index.html"
        mode: '0644'
      notify: restart httpd
    
    - name: Ensure httpd is running
      ansible.builtin.service:
        name: httpd
        state: started
        enabled: yes
  
  handlers:
    - name: restart httpd
      ansible.builtin.service:
        name: httpd
        state: restarted
<!-- ~/ansible/templates/index.html.j2 -->
<html>
<body>
<h1>{{ welcome_message }}</h1>
<p>Port: {{ http_port }}</p>
<p>Host: {{ ansible_fqdn }}</p>
<p>OS: {{ ansible_distribution }} {{ ansible_distribution_version }}</p>
</body>
</html>

Guided Lab​

  1. Create a variables file

    # ~/ansible/vars/web.yml
    ---
    web_package: httpd
    web_service: httpd
    web_port: 8080
    admin_email: admin@example.com

  2. Create a Jinja2 template

    # ~/ansible/templates/motd.j2
    Welcome to {{ ansible_hostname }}
    Managed by Ansible
    Contact: {{ admin_email }}
    Date: {{ ansible_date_time.date }}

  3. Write a playbook with variables, template, and handler

    # ~/ansible/configure-web.yml
    ---
    - name: Configure web server
      hosts: webservers
      become: yes
      vars_files:
        - vars/web.yml
      
      tasks:
        - name: Install web package
          ansible.builtin.package:
            name: "{{ web_package }}"
            state: present
        
        - name: Deploy MOTD
          ansible.builtin.template:
            src: templates/motd.j2
            dest: /etc/motd
            mode: '0644'
        
        - name: Ensure web service is running
          ansible.builtin.service:
            name: "{{ web_service }}"
            state: started
            enabled: yes

  4. Add conditionals and loops

    # ~/ansible/conditional-loops.yml
    ---
    - name: Conditionals and loops example
      hosts: all
      become: yes
      vars:
        packages_to_install:
          - vim
          - curl
          - wget
        target_os: "RedHat"
      
      tasks:
        - name: Install packages with loop
          ansible.builtin.package:
            name: "{{ item }}"
            state: present
          loop: "{{ packages_to_install }}"
        
        - name: Only run on RedHat
          ansible.builtin.command: "echo 'Running on RedHat'"
          when: ansible_os_family == target_os
        
        - name: Create files conditionally
          ansible.builtin.file:
            path: "/tmp/{{ item }}"
            state: touch
          loop:
            - file1.txt
            - file2.txt
            - file3.txt
          when: ansible_distribution_major_version == "9"

  5. Run the playbooks

    ansible-playbook -i ~/ansible/inventory.ini ~/ansible/configure-web.yml
    ansible-playbook -i ~/ansible/inventory.ini ~/ansible/conditional-loops.yml

  6. Verify results

    # On managed node
    cat /etc/motd
    systemctl status httpd
    rpm -q vim curl wget

Expected output: Playbooks run successfully, templates render with variables, conditionals work, loops create multiple files, handlers restart services.

Exam Tip

Use ansible_facts to access system information (ansible_distribution, ansible_fqdn, ansible_memory_mb, etc.). Run ansible all -m setup to see all facts.

Challenge Trial​

Without looking at the steps:

  • Create a vars file with custom variables
  • Write a Jinja2 template with {{ variable }} placeholders
  • Write a playbook that uses vars_files and templates
  • Add a handler that restarts a service on change
  • Use a loop to install multiple packages
  • Use a when conditional to run tasks only on certain OS
  • Run the playbook and verify results on managed nodes

Quiz​

Q1: Which Ansible keyword runs a task only when a condition is true?

Answer: when: evaluates a condition and skips the task if false.

Q2: Which Jinja2 syntax outputs a variable in a template?

Answer: {{ variable }} — Jinja2 uses double curly braces for variable substitution.

Q3: Which keyword repeats a task for each item in a list?

Answer: loop: iterates over a list and runs the task once per item.

Exam Tip

Handlers only run if a task reports a change. Use notify: to trigger handlers from tasks that modify files or packages.
