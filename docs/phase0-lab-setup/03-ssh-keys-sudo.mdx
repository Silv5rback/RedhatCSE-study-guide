# Phase 0, Module 3 — SSH Keys & Sudo

## Theory

SSH key-based authentication is more secure than passwords and is required for:
- Connecting from your Windows host to the lab VM
- The ttyd backend (if you proxy through SSH)
- Ansible management (Phase 2)

Sudo allows your regular user to run administrative commands without logging in as root.

## Try It

Generate an SSH key on Windows:

```powershell
ssh-keygen -t ed25519 -C "rhcse-lab"
```

Copy the public key to your VM:

```powershell
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh user@<vm-ip> "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

## Guided Lab

### On the lab VM:

1. **Ensure SSH server is running**
   ```bash
   sudo systemctl enable --now sshd
   sudo systemctl status sshd
   ```

2. **Create your user (if not done during install)**
   ```bash
   sudo useradd -m -G wheel rhcse
   sudo passwd rhcse
   ```

3. **Add your SSH public key**
   ```bash
   sudo mkdir -p /home/rhcse/.ssh
   sudo nano /home/rhcse/.ssh/authorized_keys
   # Paste your Windows public key here
   sudo chown -R rhcse:rhcse /home/rhcse/.ssh
   sudo chmod 700 /home/rhcse/.ssh
   sudo chmod 600 /home/rhcse/.ssh/authorized_keys
   ```

4. **Verify sudo access**
   ```bash
   sudo -l
   ```

5. **Test SSH from Windows**
   ```powershell
   ssh rhcse@<vm-ip>
   ```

**Expected output:** You log in without a password prompt, and `sudo -l` shows your user can run commands as root.

:::tip Exam Tip
On the RHCSA exam, you'll use sudo constantly. Know that wheel group members can sudo by default on RHEL.
:::

## Challenge Trial

Set up SSH key auth and sudo without looking at the steps. Verify:

- [ ] sshd is enabled and running (`systemctl status sshd`)
- [ ] Your Windows user can SSH into the VM without a password
- [ ] Your user is in the wheel group
- [ ] `sudo -l` shows your user has administrative access
- [ ] You can run sudo commands without a password prompt (if configured)

## Quiz

<details>
<summary><strong>Q1: Which file stores authorized SSH public keys on a Linux server?</strong></summary>
<p><strong>Answer:</strong> `~/.ssh/authorized_keys` contains public keys that are allowed to log in as that user.</p>
</details>

<details>
<summary><strong>Q2: Which group grants sudo access by default on RHEL?</strong></summary>
<p><strong>Answer:</strong> On RHEL, members of the wheel group can use sudo (configured in `/etc/sudoers`).</p>
</details>

:::tip Exam Tip
Disable password authentication in `/etc/ssh/sshd_config` after you verify SSH keys work — it's more secure and exam-like.
:::
