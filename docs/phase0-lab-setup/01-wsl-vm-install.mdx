# Phase 0, Module 1 — WSL2 & VM Install

## Theory

Before you can practice RHCSA/RHCE tasks, you need a lab environment. Red Hat exams are performance-based and run on RHEL, so your lab should match as closely as possible.

**Options:**
- **WSL2 + RHEL** — Best Windows integration, runs a real Linux kernel, good for ttyd backend
- **VirtualBox / VMware** — Full VM isolation, easier snapshots, closer to bare-metal exam experience
- **Cloud (AWS/Azure)** — No local resources needed, but costs money and requires internet

**Recommended:** WSL2 with a RHEL-compatible distro (AlmaLinux, Rocky Linux, or CentOS Stream) for the ttyd backend, plus a full RHEL VM for the main lab machine.

## Try It

Check if WSL2 is already available:

```powershell
wsl --list --verbose
```

If you see `WSL 2` in the VERSION column, you're ready. If not, install it:

```powershell
wsl --install
```

Then restart your computer.

:::tip Exam Tip
WSL2 requires Windows 10 version 1903+ or Windows 11. Enable Virtual Machine Platform in Windows Features first if `wsl --install` fails.
:::

## Guided Lab

1. **Install WSL2**
   ```powershell
   wsl --install
   ```
   Restart when prompted.

2. **Install a RHEL-compatible distro from Microsoft Store**
   - Search for "AlmaLinux" or "Rocky Linux" in the Microsoft Store
   - Or use the command line:
     ```powershell
     wsl --install -d AlmaLinux
     ```

3. **Launch your distro**
   ```powershell
   wsl -d AlmaLinux
   ```

4. **Update packages**
   ```bash
   sudo dnf update -y
   ```

5. **Verify you're in a real Linux shell**
   ```bash
   uname -r
   cat /etc/redhat-release
   ```

**Expected output:** A kernel version starting with `5.15` or `6.x` (WSL2), and `AlmaLinux release 9.x` or similar.

## Challenge Trial

Install WSL2 and a RHEL-compatible distro without looking at the steps above. Verify:

- [ ] WSL2 is running (`wsl --list --verbose` shows VERSION 2)
- [ ] A RHEL-compatible distro is installed (AlmaLinux, Rocky, or CentOS Stream)
- [ ] You can launch the distro with `wsl -d <distro>`
- [ ] `dnf update` runs without errors
- [ ] `uname -r` shows a Linux kernel version

## Quiz

<details>
<summary><strong>Q1: Which WSL command lists installed distributions with their version?</strong></summary>
<p><strong>Answer:</strong> `wsl --list --verbose` (or `wsl -l -v`) shows all installed distros, their state, and WSL version (1 or 2).</p>
</details>

<details>
<summary><strong>Q2: Which command installs AlmaLinux via WSL?</strong></summary>
<p><strong>Answer:</strong> `wsl --install -d AlmaLinux` installs a specific distribution from the Microsoft Store catalog.</p>
</details>

:::tip Exam Tip
The RHCSA exam runs on RHEL. AlmaLinux and Rocky Linux are binary-compatible with RHEL and make excellent, free lab stand-ins.
:::
