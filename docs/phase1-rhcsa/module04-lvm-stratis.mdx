# Phase 1, Module 4 — LVM & Stratis

## Theory

LVM (Logical Volume Manager) is critical for RHCSA. Key concepts:

- **Physical Volume (PV)** — A disk or partition initialized for LVM (`pvcreate`)
- **Volume Group (VG)** — A pool of PVs (`vgcreate`)
- **Logical Volume (LV)** — A virtual partition carved from a VG (`lvcreate`)
- **Filesystem** — Formatted on an LV (`mkfs.xfs`)
- **Mounting** — LV mounted via /etc/fstab
- **Snapshots** — Point-in-time copies of an LV (`lvcreate -s`)

**Stratis** — A newer storage layer that simplifies LVM + filesystem management (`stratis` command).

**Exam reality:** You'll create LVM volumes, resize them (extend/reduce), create snapshots, and mount them persistently. XFS can be extended but NOT reduced (ext4 can be reduced).

## Try It

```bash
# Initialize physical volumes
sudo pvcreate /dev/sdb1 /dev/sdc1

# Create volume group
sudo vgcreate vg_data /dev/sdb1 /dev/sdc1

# Create logical volume
sudo lvcreate -L 5G -n lv_app vg_data

# Format and mount
sudo mkfs.xfs /dev/vg_data/lv_app
sudo mkdir -p /mnt/app
sudo mount /dev/vg_data/lv_app /mnt/app

# Add to fstab
echo "/dev/mapper/vg_data-lv_app  /mnt/app  xfs  defaults  0  0" | sudo tee -a /etc/fstab

# Extend an LV (XFS can grow online)
sudo lvextend -L +2G /dev/vg_data/lv_app
sudo xfs_growfs /mnt/app

# Create a snapshot
sudo lvcreate -L 1G -s -n lv_app_snap /dev/vg_data/lv_app
```

## Guided Lab

1. **Check existing storage**
   ```bash
   lsblk
   sudo pvs
   sudo vgs
   sudo lvs
   ```

2. **Initialize physical volumes** (use spare disks/partitions)
   ```bash
   sudo pvcreate /dev/sdb1
   sudo pvcreate /dev/sdc1
   ```

3. **Create a volume group**
   ```bash
   sudo vgcreate vg_rhcsa /dev/sdb1 /dev/sdc1
   sudo vgs
   ```

4. **Create logical volumes**
   ```bash
   # 5 GB for application data
   sudo lvcreate -L 5G -n lv_app vg_rhcsa
   
   # 2 GB for user data
   sudo lvcreate -L 2G -n lv_users vg_rhcsa
   sudo lvs
   ```

5. **Format and mount lv_app**
   ```bash
   sudo mkfs.xfs /dev/vg_rhcsa/lv_app
   sudo mkdir -p /mnt/app
   sudo mount /dev/vg_rhcsa/lv_app /mnt/app
   
   # Get the device mapper path
   lsblk | grep lv_app
   ```

6. **Add to /etc/fstab**
   ```bash
   echo "/dev/mapper/vg_rhcsa-lv_app  /mnt/app  xfs  defaults  0  0" | sudo tee -a /etc/fstab
   sudo mount -a
   ```

7. **Extend lv_app by 2 GB**
   ```bash
   sudo lvextend -L +2G /dev/vg_rhcsa/lv_app
   sudo xfs_growfs /mnt/app
   df -h | grep /mnt/app   # Should show ~7 GB now
   ```

8. **Create a snapshot of lv_app**
   ```bash
   sudo lvcreate -L 1G -s -n lv_app_snapshot /dev/vg_rhcsa/lv_app
   sudo lvs   # Should show the snapshot
   ```

9. **Remove the snapshot when done**
   ```bash
   sudo lvremove /dev/vg_rhcsa/lv_app_snapshot
   ```

10. **Explore Stratis (optional)**
    ```bash
    sudo dnf install -y stratis-cli
    stratis --version
    ```

**Expected output:** VG created with PVs, LVs created/formatted/mounted, fstab entry works, LV extended and filesystem grown, snapshot created and removed.

:::tip Exam Tip
XFS filesystems can be extended online (while mounted) but CANNOT be reduced. Plan your LV sizes carefully before creating.
:::

## Quiz

<details>
<summary><strong>Q1: Which command creates a physical volume for LVM?</strong></summary>
<p><strong>Answer:</strong> `pvcreate` initializes a disk or partition for use by LVM.</p>
</details>

<details>
<summary><strong>Q2: Which filesystem can be extended online but NOT reduced?</strong></summary>
<p><strong>Answer:</strong> XFS supports online growth via `xfs_growfs` but does not support shrinking.</p>
</details>

<details>
<summary><strong>Q3: Which command creates an LVM snapshot?</strong></summary>
<p><strong>Answer:</strong> `lvcreate -L <size> -s -n <name> <vg>/<lv>` creates a snapshot.</p>
</details>

:::tip Exam Tip
Always ensure you have free space in the VG before extending an LV. Use `vgs` to check available space.
:::
