# Phase 1, Module 5 — DNF Package Management

## Theory

DNF is RHEL's package manager. You need to know:

- **Package queries** — `dnf list`, `dnf search`, `dnf info`, `rpm -q`
- **Install/remove** — `dnf install`, `dnf remove`, `dnf erase`
- **Updates** — `dnf update`, `dnf upgrade`
- **Repositories** — `/etc/yum.repos.d/`, `dnf repolist`, `dnf config-manager`
- **Modules** — `dnf module list`, `dnf module install`, `dnf module enable` (AppStream)
- **Package files** — `rpm -ql`, `rpm -qf`, `rpm -qi`

**Exam reality:** You'll install packages, enable/disable repositories, and manage modules. Know how to find which package owns a file.

## Try It

```bash
# Search for a package
dnf search httpd

# Get package info
dnf info httpd

# List installed packages matching a pattern
dnf list installed | grep ssh

# Install a package
sudo dnf install -y vim-enhanced

# Remove a package
sudo dnf remove -y vim-enhanced

# Update all packages
sudo dnf update -y

# List repositories
dnf repolist

# Check which package owns a file
rpm -qf /usr/bin/vim

# List files in a package
rpm -ql httpd

# Module management
dnf module list
dnf module install -y nodejs:18
```

## Guided Lab

1. **Search for a package**
   ```bash
   dnf search nginx
   ```

2. **Get detailed package information**
   ```bash
   dnf info nginx
   ```

3. **Check if a package is installed**
   ```bash
   dnf list installed | grep vim
   rpm -q vim-enhanced
   ```

4. **Install a package**
   ```bash
   sudo dnf install -y vim-enhanced
   ```

5. **Verify installation**
   ```bash
   rpm -q vim-enhanced
   which vim
   vim --version | head -3
   ```

6. **Find which package owns a file**
   ```bash
   rpm -qf /usr/bin/vim
   rpm -qf /etc/hosts
   ```

7. **List files provided by a package**
   ```bash
   rpm -ql httpd | head -20
   ```

8. **Manage repositories**
   ```bash
   dnf repolist
   dnf repolist all
   ls /etc/yum.repos.d/
   cat /etc/yum.repos.d/rhel-appstream.repo | head -30
   ```

9. **Enable/disable a repository**
   ```bash
   sudo dnf config-manager --set-enabled rhel-9-for-x86_64-appstream-rpms
   sudo dnf config-manager --set-disabled rhel-9-for-x86_64-appstream-rpms
   ```

10. **Work with modules**
    ```bash
    dnf module list
    dnf module info nodejs
    sudo dnf module install -y nodejs:18
    node --version
    ```

11. **Clean DNF cache**
    ```bash
    sudo dnf clean all
    ```

**Expected output:** Packages installed/removed, repo info visible, file ownership resolved, modules installed and usable.

:::tip Exam Tip
`rpm -qf <file>` tells you which package owns a file — essential for troubleshooting missing commands or config files.
:::

## Quiz

<details>
<summary><strong>Q1: Which command shows which package owns a file?</strong></summary>
<p><strong>Answer:</strong> `rpm -qf <file>` queries the package that owns the specified file.</p>
</details>

<details>
<summary><strong>Q2: Which directory contains DNF repository configuration files?</strong></summary>
<p><strong>Answer:</strong> `/etc/yum.repos.d/`</p>
</details>

<details>
<summary><strong>Q3: Which DNF command lists available software modules?</strong></summary>
<p><strong>Answer:</strong> `dnf module list` shows all available modules and their streams.</p>
</details>

:::tip Exam Tip
Always use `sudo dnf install -y` in lab scripts. On the exam, install packages efficiently — know the exact package name before you start.
:::
