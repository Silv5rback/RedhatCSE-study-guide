# Phase 1, Module 3 — Storage

## Theory

Storage is a major RHCSA topic. You need to know:

- **Partitioning** — `fdisk`, `parted`, `lsblk`, `blkid`
- **Filesystems** — XFS (default on RHEL), ext4, `mkfs.xfs`, `mkfs.ext4`
- **Mounting** — `mount`, `umount`, `/etc/fstab`, `systemctl mount` (systemd mount units)
- **Swap** — `mkswap`, `swapon`, `/etc/fstab` swap entries
- **UUIDs** — Using UUID instead of device names in fstab (more reliable)

**Exam reality:** You'll create partitions, format filesystems, mount them persistently via /etc/fstab, and configure swap. Mistakes in /etc/fstab can make the system unbootable.

## Try It

```bash
# List block devices
lsblk

# Identify filesystems
blkid
df -h

# Create a filesystem
sudo mkfs.xfs /dev/sdb1

# Mount temporarily
sudo mount /dev/sdb1 /mnt

# Make permanent in /etc/fstab
echo "UUID=<uuid>  /mnt  xfs  defaults  0  0" | sudo tee -a /etc/fstab

# Test fstab (without rebooting)
sudo mount -a

# Check swap
sudo swapon --show
free -h
```

## Guided Lab

1. **Identify available disks**
   ```bash
   lsblk
   sudo fdisk -l
   ```

2. **Create a partition on a spare disk**
   ```bash
   # Assuming /dev/sdb is a spare disk
   sudo fdisk /dev/sdb
   # n (new), p (primary), 1 (partition number), Enter (default start), Enter (default end), w (write)
   ```

3. **Format the partition as XFS**
   ```bash
   sudo mkfs.xfs /dev/sdb1
   ```

4. **Get the UUID**
   ```bash
   sudo blkid /dev/sdb1
   ```

5. **Create a mount point**
   ```bash
   sudo mkdir -p /mnt/data
   ```

6. **Add to /etc/fstab using UUID**
   ```bash
   # Get the UUID first
   UUID=$(sudo blkid -s UUID -o value /dev/sdb1)
   echo "UUID=$UUID  /mnt/data  xfs  defaults  0  0" | sudo tee -a /etc/fstab
   ```

7. **Mount and verify**
   ```bash
   sudo mount -a
   df -h | grep /mnt/data
   ```

8. **Verify it persists (simulate by remounting)**
   ```bash
   sudo umount /mnt/data
   sudo mount -a
   df -h | grep /mnt/data
   ```

9. **Configure swap**
   ```bash
   # Create a swap file
   sudo dd if=/dev/zero of=/swapfile bs=1M count=2048
   sudo chmod 600 /swapfile
   sudo mkswap /swapfile
   sudo swapon /swapfile
   
   # Add to fstab
   echo "/swapfile  swap  swap  defaults  0  0" | sudo tee -a /etc/fstab
   
   # Verify
   free -h
   sudo swapon --show
   ```

**Expected output:** New partition formatted, mounted at /mnt/data, listed in fstab, persists across mount/unmount. Swap file active and shown in free output.

:::tip Exam Tip
Always test `/etc/fstab` with `mount -a` before rebooting. A typo in fstab can drop you to emergency mode.
:::

## Quiz

<details>
<summary><strong>Q1: Which filesystem is the default on RHEL 9?</strong></summary>
<p><strong>Answer:</strong> XFS is the default filesystem on RHEL 7, 8, and 9.</p>
</details>

<details>
<summary><strong>Q2: Which fstab field specifies the filesystem type?</strong></summary>
<p><strong>Answer:</strong> Field 3. /etc/fstab fields: 1=device/UUID, 2=mount point, 3=filesystem type, 4=options, 5=dump, 6=pass.</p>
</details>

<details>
<summary><strong>Q3: Which command validates /etc/fstab without rebooting?</strong></summary>
<p><strong>Answer:</strong> `mount -a` mounts all filesystems listed in fstab. If it errors, fix fstab before rebooting.</p>
</details>

:::tip Exam Tip
Use UUIDs in /etc/fstab, not device names like /dev/sdb1. Device names can change between reboots; UUIDs are permanent.
:::
