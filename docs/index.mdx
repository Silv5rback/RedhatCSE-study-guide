# Welcome to RedhatCSE

**RedhatCSE** is a fully interactive, web-based study guide for the Red Hat Certified Systems Engineer path — starting from RHCSA foundations and progressing through RHCE-level Ansible automation.

## What you'll find here

| Phase | Modules | Focus |
|-------|---------|-------|
| **Phase 0 — Lab Environment Setup** | 4 | WSL2, RHEL VM, SSH, ttyd backend for live shell labs |
| **Phase 1 — RHCSA Foundations** | 8 | Shell, systemd, storage, LVM, DNF, users, SELinux, firewalld |
| **Phase 2 — RHCE / Ansible** | 6 | Playbooks, roles, Jinja2, Ansible Vault, RHEL management |
| **Resources** | 3 | Exam objectives, cheatsheets, troubleshooting |

## How to use this guide

Each module follows the same interactive loop:

1. **Theory** — Concept explained in plain language + why it matters on the exam
2. **Try It** — Copy-paste commands with expected output (safe to run in your lab VM)
3. **Guided Lab** — Step-by-step build with verification commands at each step
4. **Challenge Trial** — "Do this without the steps" — scenario with verification checklist
5. **Quiz** — Interactive scored questions with answer explanations (expandable details)
6. **Exam Tip** — Common pitfalls and what the proctors actually check

## Live shell labs

Some modules reference a **live shell** — a real xterm.js terminal in your browser connected to a ttyd backend running on WSL2/Linux. This lets you practice commands in a live RHEL shell without leaving the guide.

> ⚠️ The live shell requires a ttyd backend running on WSL2 or a Linux VM. See [Phase 0, Module 4](./phase0-lab-setup/04-ttyd-backend) for setup instructions. A dedicated lab shell page is available at [/lab-shell](/lab-shell).

## Prerequisites

- **Windows 11** with WSL2 enabled
- **Node.js LTS** (for local development of this guide itself)
- **draw.io desktop** (optional, for editing diagram sources)
- A RHEL-compatible VM (RHEL, CentOS Stream, AlmaLinux, or Rocky Linux)
